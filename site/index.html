# Stream ASR + LLM in 6 lines
from voxcore import Engine

async with Engine(asr="whisper-local", llm="gpt-4o-mini") as e:
    async for chunk in e.stream(mic=True):
        print(chunk.text, end="")
// Core

Built for low latency, designed for swap-in.

A single facade hides the complexity of audio capture, ASR streaming, LLM token streams, and TTS playback. Adapters are pluggable — bring your own model.

// Products

One engine. Two desktop apps. Open-source today.

VoxCore is the SDK. VoxStream and VoxNote are reference end-user products built on top of it — fully open-source, downloadable today.

@voxcore/sdk

VoxCore

The streaming voice AI engine. Mic → ASR → LLM → TTS in one async iterator. Adapters for Whisper, OpenAI, DeepSeek, Edge-TTS.
